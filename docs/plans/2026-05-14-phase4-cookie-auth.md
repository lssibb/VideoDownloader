# Phase 4: Cookie Authentication Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement Google Account login via BrowserWindow, extract YouTube cookies, convert to Netscape format, and pass them to yt-dlp for authenticated downloads.

**Architecture:** Main Process opens a modal `BrowserWindow` for Google login. On download start, if `useCookies` is enabled, cookies for `.youtube.com` are retrieved, converted to Netscape format, written to a temp file, and passed to yt-dlp via `--cookies`. The temp file is deleted after download completion or error.

**Tech Stack:** Electron `session`, `BrowserWindow`, `cookies.get`, `child_process.spawn`, Node.js `fs`, `os.tmpdir()`.

```typescript
import { BrowserWindow } from 'electron'

let authWindow: BrowserWindow | null = null

export function openGoogleAuthWindow(): Promise<void> {
  return new Promise((resolve, reject) => {
    if (authWindow && !authWindow.isDestroyed()) {
      authWindow.focus()
      return
    }

    authWindow = new BrowserWindow({
      width: 800,
      height: 900,
      webPreferences: {
        contextIsolation: true,
        nodeIntegration: false
      }
    })

    authWindow.loadURL('https://accounts.google.com')

    authWindow.on('closed', () => {
      authWindow = null
      resolve()
    })

    authWindow.webContents.on('did-navigate', (_, url) => {
      if (url.startsWith('https://myaccount.google.com')) {
        authWindow?.close()
        resolve()
      }
    })
  })
}
```

## Task 2: JSON to Netscape cookie converter

**Files:**
- Create: `src/main/netscape-cookie.ts`

- [ ] **Step 1: Write netscape-cookie.ts**

```typescript
import fs from 'node:fs'
import path from 'node:path'
import os from 'node:os'

interface ElectronCookie {
  name: string
  value: string
  domain: string
  path: string
  secure: boolean
  httpOnly: boolean
  expirationDate?: number
  sameSite?: string
}

export function convertToNetscape(cookies: ElectronCookie[]): string {
  const lines: string[] = [
    '# Netscape HTTP Cookie File',
    '# This file was generated by Video Downloader. Edit at your own risk.',
    ''
  ]

  for (const cookie of cookies) {
    const domain = cookie.domain.startsWith('.') ? cookie.domain : '.' + cookie.domain
    const flag = domain.startsWith('.') ? 'TRUE' : 'FALSE'
    const path = cookie.path || '/'
    const secure = cookie.secure ? 'TRUE' : 'FALSE'
    const expires = cookie.expirationDate ? Math.floor(cookie.expirationDate) : '0'
    lines.push([domain, flag, path, secure, expires, cookie.name, cookie.value].join('	'))
  }

  return lines.join('
') + '
'
}

export async function writeTempCookieFile(cookies: ElectronCookie[]): Promise<string> {
  const netscape = convertToNetscape(cookies)
  const tmpPath = path.join(os.tmpdir(), `vd-cookies-${Date.now()}.txt`)
  await fs.promises.writeFile(tmpPath, netscape, 'utf-8')
  return tmpPath
}

export async function deleteTempCookieFile(filePath: string): Promise<void> {
  try {
    await fs.promises.unlink(filePath)
  } catch {
    // ignore cleanup errors
  }
}
```
